# Bridge Exploration

The polyformalism canary (0x024a555471370b18d) is canon across
classical substrates. It is NOT canon across quantum substrates
(0/5 schemes match).

This repo tries bridging strategies.

## Strategies

1. **Normalize**: replace measurement bits with canonical byte
   encoding, then hash.
2. **Partial hash**: hash only the first N measurement bits (4 or 8).
